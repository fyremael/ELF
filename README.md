# ELF

Grand Challenge Labs working repository for MODULUS-ELF: a governed overlay around the official JAX implementation of Embedded Language Flows.

This repository is initialized as an overlay repository rather than a vendored copy. The baseline source of truth is the official upstream ELF repository:

- Upstream: https://github.com/lillian039/ELF
- Paper: https://arxiv.org/abs/2605.10938

The first governed objective is to reproduce the released ELF-B OpenWebText checkpoint evaluation before introducing any MODULUS geometry changes.
